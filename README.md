# 🛒 Minha Lojinha

Projeto desenvolvido como parte do curso de programação, simulando um e-commerce completo com consumo de API.

---

## 🚀 Tecnologias utilizadas

* React
* React Router DOM
* Bootstrap
* Context API
* Fake Store API

---

## 📦 Funcionalidades

* Listagem de produtos
* Filtro por categoria
* Página de detalhes do produto
* Carrinho de compras

  * Adicionar produtos
  * Remover produtos
  * Alterar quantidade
  * Limpar carrinho
* Persistência com localStorage
* Dark mode
* Loading e tratamento de erro

---

## ▶️ Como rodar o projeto

```bash
npm install
npm run dev
```
